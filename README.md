# 💼 ApplyMatrix – Job Application Tracker

ApplyMatrix is a full-stack job application tracking platform built using the MERN stack. It helps job seekers organize, track, and manage their job applications efficiently through a centralized dashboard with search, filtering, and status management capabilities.

---

## 🚀 Live Demo

🔗 https://apply-matrix-eta.vercel.app/

---

## 📖 Project Overview

ApplyMatrix simplifies the job search process by providing a structured system to manage applications across different companies and positions.

Users can track application statuses, organize job opportunities, monitor progress, and maintain a complete record of their job search journey.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Ashwani895/ApplyMatrix.git
```

### Navigate to Project

```bash
cd ApplyMatrix
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

### Configure Environment Variables

Create a `.env` file in the server folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start Backend Server

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```
